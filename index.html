Facial Emotion Recognition

Real-time and batch emotion analysis from webcam or images. Detects seven emotions with Haar cascade face detection (four tunable configs) and a CNN trained on FER-2013. Batch mode computes accuracy and a confusion matrix on a labelled dataset.

  • Live bounding box, label and emotion bar chart
  • Frame skipping, screenshots, config switching
  • Exports results.csv + confusion matrix
